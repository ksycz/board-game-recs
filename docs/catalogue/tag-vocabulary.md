# Tag Vocabulary: draft for Admin review

> **Status: REVIEWED** with the Admin on 2026-10-19. Further changes go through review comments. Once approved, this becomes the data file the recommender and tests use, and only the Admin changes it from then on (see `CONTEXT.md` → Tag Vocabulary).

Each Tag has a short id (used in code and tests), a plain-English meaning (what Members see), and examples to make the meaning concrete. Examples are illustrations, not final Catalogue tagging.

**Rules for a good Tag:**
- Members can recognise it in their own words.
- It separates Games that people actually like or dislike for different reasons.
- It does not duplicate another Tag.

## Pace: how the time feels (6)

| Id | Meaning | Examples |
|---|---|---|
| `filler` | A short game (about 10–20 minutes) to play between bigger ones or on a coffee break | Spots, Sushi Go! |
| `quick-turns` | Turns are short; there's little waiting for others | Splendor, Sushi Go! |
| `downtime` | You may wait a while between your turns | Twilight Imperium, Terraforming Mars at 5 |
| `analysis-paralysis` | So many options each turn that some players freeze and the game slows down | Ark Nova, Terraforming Mars |
| `simultaneous` | Everyone takes their turn at the same time | 7 Wonders, Cartographers |
| `slow-burn` | The game builds up slowly and the payoff comes late | Brass: Birmingham, Agricola |

**Total: 63 Tags.** `analysis-paralysis` is about *why* a game slows (too many choices); `downtime` is about *how long* you wait between turns. A Game can have one without the other. `newcomer-friendly` is a Tag a Game can carry; it is not the same as a **Gateway Game**, which is one of the Games used in the Interview grid (see `CONTEXT.md`). `solitary` was renamed `multiplayer-solitaire`, the term players actually use. Candidates to cut or merge if you want fewer: `dramatic` (overlaps `chaotic`), `traitor` (overlaps `social-deduction`), `dexterity`, `slow-burn` (overlaps `strategic`).
