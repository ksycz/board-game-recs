# Own curated catalogue first; BGG optional later

We build and own the game Catalogue (hand-curated, AI-drafted entries checked by a person) instead of depending on BoardGameGeek, so we can start without waiting for BGG API approval, define tags and Complexity exactly as recommendations need them, and keep the option of charging money later. Every Game carries an optional BGG ID so BGG can be plugged in later for catalogue breadth and Collection imports if access is granted.

## Consequences

- Buy mode can only recommend games in our Catalogue; breadth grows by curation and user additions.
- No community ratings at first: quality signal comes from curation, later from in-app ratings.
- Data must not be copied from BGG (EU database right); facts come from boxes and publishers.
- No ready alternative API exists: Board Game Atlas shut down on 1 Oct 2023.
